# Penny's Heavy Duty & Auto

A responsive multi-page business website designed and developed for Penny's Heavy Duty & Auto, a mobile automotive and heavy-duty repair business in Prince George, British Columbia.

🌐 **Live Website:** https://pennyshdauto.ca

## About the Project

This project was created for a real local business to establish its online presence and make it easy for customers to learn about available services and get in touch.

I worked with the client to determine the site's content, services, layout, and preferred contact methods, then designed, developed, tested, and launched the website.

## Features

- Responsive design for mobile, tablet, and desktop
- Multi-page website
- Service information and dedicated service content
- Business photo gallery
- Contact options designed around the client's preferred communication methods
- Accessible HTML structure
- Search engine optimization (SEO)
- Social sharing metadata
- Google Analytics integration
- Google Search Console setup
- Responsive image optimization

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Analytics
- Google Search Console
- Git & GitHub

## What I Learned

This project gave me experience taking a website from initial client requirements through design, development, testing, deployment, and ongoing improvements.

I also gained practical experience with responsive design, accessibility, SEO, website analytics, troubleshooting, and building a website around the needs of a real business.
